How is each statistic calculated?

EMV = Σ (probability of state × payoff in that state). Max / Min payoff = best / worst payoff of the alternative.

Regret in a state = best payoff among all alternatives in that state − this alternative's payoff. Max regret = its largest regret. These benchmarks use the full original table and do not change during filtering.

3. Criterion decisions

Each criterion looks at the full set of alternatives. They can disagree, because each one reflects a different attitude toward risk.

4. Staged filtering

Apply criteria one after another. Each stage only looks at the survivors of the previous one, and eliminated alternatives never come back. Ties at the cutoff all survive.
