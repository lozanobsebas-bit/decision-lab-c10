1Payoff table

Payoffs are gains, so a higher number is better. States of nature are rows and alternatives are columns. Tip: arrow up/down or Enter moves between rows.

2Summary

One row per alternative. Highlighted cells show the winner of each criterion; two values closer than 0.000000001 count as a tie. Results show two decimals but are calculated with full precision.

3Decision by criterion

Each criterion looks at all the original alternatives. Different criteria can recommend different alternatives.

4Staged filtering

Build an ordered list of stages. Each stage ranks only the survivors of the stage before it. Eliminated alternatives never come back, and alternatives tied at the cut-off all survive. Regret is always measured against the full original table.
