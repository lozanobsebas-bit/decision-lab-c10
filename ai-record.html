AI development record

How the Decision Lab webpage (Grade 10 · Global Economics · Criterion 10) was developed with an AI assistant.

Summary

This webpage was developed with Claude, an AI assistant made by Anthropic, used through the Claude desktop app. The student asked the assistant to read the Criterion 10 instructions from the course on the school's virtual classroom (Open), build the webpage, test it, and publish it on GitHub Pages. The assistant wrote all the code, checked the calculations, and created the repository and the public site.

This page is a written record, not a word-for-word transcript. Parts of the original conversation that have nothing to do with this assignment (personal files and unrelated school matters) were left out. Nothing here changes what was asked or what the AI did.

What was asked

Paraphrased from the student's request:

Read the instructions for the Criterion 10 task in the Global Economics course on Open. The task is to create a working webpage with a GitHub repository that does everything we did this term. Follow the instructions and the reference example, make it the way the teacher would like it, and take care of GitHub too.

The AI was then given access to the course page, where it found the task “C10 – Webpage” and the teacher's instruction document (Interactive Decision Webpage: C10 Practice).

What the AI did, step by step

  1. Read the requirements. It opened the teacher's instruction document and the reference dashboard to understand the five requirements: interactive model, two or more preloaded examples, usability and validation, this AI record, and submitting only the public URL.
  2. Designed and wrote the page. It wrote its own code and its own visual design in a single file (index.html), with the same functionality the instructions ask for: editable alternatives, states, payoffs and probabilities; Maximax, Maximin, Minimax Regret and EMV with tie detection; staged filtering with editable stages; and a flow diagram.
  3. Tested it. It ran the page locally and checked the three preloaded examples against calculations done by hand, including the ties. It also tested invalid inputs (blank cells, probabilities that do not add to 1, an invalid k), adding and removing alternatives, states and stages, and the phone-size layout. It found and fixed two small layout problems.
  4. Published it. It created the public GitHub repository decision-lab-c10, uploaded the page, turned on GitHub Pages, and checked that the live site works.
  5. Added this record. At the student's request, it wrote this page and linked it from the webpage (requirement 4).

The student's role

  • Decided what to build and gave the AI the task and the instructions to follow.
  • Signed in to the school's classroom and to GitHub, so the AI could read the task and publish.
  • Reviews the result and is responsible for understanding how the page works.
